# tanos.co.uk grammar lists (archived)

Jonathan Waller's JLPT grammar lists, licensed CC BY, credited in
[content/references.yaml](../../content/references.yaml). The live site returned
server errors in September 2026, so the pages this work was seeded from are kept
here exactly as the Internet Archive served them.

| sharing.html (licence) | https://web.archive.org/web/20251114165345/https://www.tanos.co.uk/jlpt/sharing/ |

`scripts/import-tanos.mjs` reads these files. It adds a stub for each point
not yet in `content/grammar/` and never changes an entry that exists.
